# MedPal 医院宣传信息管理系统 V1.2.0

**仓库地址**：https://github.com/zjmnt1992/MedPal

> ⚠️ **部署提示**：因医院信息安全要求，不建议公网部署；无内网 DNS 可关闭 Nginx 部署。
> ⚠️ **容量建议**：本系统结构轻量且简单，适合服务器存储资源紧张的单位使用，总用户数不建议超过 3000，并发不建议超过 50。

基于 Python FastAPI + React + SQLite 的轻量化医护信息管理系统：内置完整权限体系、人员审核、标识管理、消息通知与自动运维能力，开箱即用、无需复杂数据库迁移。

---

## 📌 核心功能

- **人员全流程管理**：医护行政人员统一管理、在职/离职状态管控、180 天离职档案保留、工号唯一不可修改
- **分级审核机制**：人员信息变更即时生效 + 追认审核，免审/科室级/超管级三级字段权限，超时自动升级、驳回回滚
- **RBAC 精细化权限**：47 个权限点，支持科室/工种双向数据隔离（个人/管辖/全局三种权限范围）
- **科室与标识管理**：科室信息/特色设备管理、院区平面图打点、标识台账、巡检维修、状态预警看板
- **消息与注册审核**：全站站内信通知、批量群发、业务跳转；可开关自助注册 + IP 限流风控
- **制度与数据管理**：制度版本管控、历史快照留存、Excel 批量导入导出、图片打包下载
- **智能运维能力**：数据库自愈、每日自动备份、孤儿文件清理、日志自动轮转、磁盘/库大小监控告警
- **安全防护体系**：双 Token 认证、登录限流、密码哈希、操作审计日志、富文本内容清洗 。

## 🚀 快速启动（本地开发）

**环境要求**：Python 3.11+、Node.js 18+

### 1. 初始化配置

```bash
# 复制环境变量配置
cp .env.example .env

# 生成安全密钥（必须替换默认值，否则无法启动）
python -c "import secrets; print(secrets.token_urlsafe(64))"
```

### 2. 启动后端

```bash
pip install -r requirements.txt
cd backend && python run.py
```

- 后端地址：http://localhost:5000
- 接口文档：http://localhost:5000/docs

### 3. 启动前端

```bash
cd frontend && npm install && npm run dev
```

- 前端地址：http://localhost:5173

## 🏗️ 部署架构

```text
用户 → Nginx (80/443) → 静态资源 / 后端 API 服务
```

统一容器化部署，Nginx 承载静态资源与反向代理，Supervisor 托管进程，数据与代码完全隔离，升级不丢数据。

**核心优势**

- 应用启动自动补齐数据库结构，无需手动迁移
- 数据统一挂载宿主机目录，容器重建数据不丢失

## 💾 数据与运维

- **数据目录隔离**：所有上传文件、数据库、日志、备份统一存放 `data/` 目录，与代码分离
- **自动备份**：每日 00:15 自动备份，默认保留 7 天备份文件，支持手动备份与恢复
- **自动清理**：定时清理孤儿图片、过期导出包、冗余日志、过期通知、历史版本数据
- **监控告警**：磁盘空间、数据库大小超限自动向管理员发送站内信告警

---

## 🛡️ 核心安全特性

- 强制密钥校验、bcrypt 密码加密、首次登录改密
- HttpOnly 刷新 Token、Token 黑名单、防 XSS 与越权
- 登录 IP 限流、自助注册风控、文件上传安全校验
- 全链路操作审计日志、90 天日志留存
